# دستیار مطالعه پرستاری

اپلیکیشن آفلاین اندروید برای مطالعه صفحه‌به‌صفحه‌ی مباحث پرستاری، با آزمون ۵ سؤالی هر صفحه،
جعبه لایتنر برای بازخوانی زمان‌بندی‌شده، انتخاب حوزه برای مطالعه رندوم، و حالت آزمون/رکورد.

## وضعیت فعلی

- موتور کامل برنامه ساخته و تست (type-check + bundle) شده ✅
- ۸ حوزه تعریف شده؛ ۳ حوزه با محتوای واقعی پر شده (فاندامنتال، داروشناسی، روان — ۷ صفحه، ۳۵ سؤال)
- ۵ حوزه دیگر (ویژه، داخلی‌جراحی، سالمندی، بهداشت جامعه، دیالیز) آماده دریافت محتوا هستند

## ساختار پروژه

```
App.tsx                  نقطه ورود، فونت‌ها، ناوبری
src/db/                  اسکیمای SQLite، کوئری‌ها، منطق جعبه لایتنر، داده‌های اولیه
src/screens/             همه صفحات برنامه
src/components/          کامپوننت‌های مشترک (کارت، دکمه، متن فارسی و...)
src/context/             تنظیمات و تم سراسری برنامه
src/navigation/          ناوبری تب‌بار + استک‌ها
src/utils/               یادآور محلی و پشتیبان‌گیری
```

## قدم بعدی: گرفتن فایل APK واقعی

ساخت APK نیاز به یک مرحله یک‌باره‌ی راه‌اندازی دارد که فقط از طریق سایت expo.dev انجام می‌شه
(نیازی به نصب چیزی روی کامپیوتر نیست):

۱. وارد expo.dev بشو (همون حسابی که به این چت وصل کردی) و یک پروژه جدید بساز، یا این پوشه رو
   با دستور زیر در یک ریپازیتوری گیت‌هاب آپلود کن:

   ```
   git init
   git add .
   git commit -m "نسخه اول"
   ```
   و آن را به یک ریپازیتوری خالی در GitHub پوش کن (یا از دکمه Upload files در سایت GitHub
   استفاده کن، بدون نیاز به خط فرمان).

۲. در داشبورد expo.dev، پروژه رو به همون ریپازیتوری گیت‌هاب وصل کن (بخش GitHub Integration).

۳. اسم کامل پروژه (چیزی شبیه `@your-username/nursing-study-app`) رو برام بفرست تا مستقیماً
   از همین‌جا یک build واقعی اندروید رو با پروفایل `preview` (خروجی APK قابل‌نصب) شروع کنم.

بعد از آن مراحل، فقط کافیه بگی «حالا build کن» — بقیه‌اش (اجرا، پیگیری، دانلود) با من است.
